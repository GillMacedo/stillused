## [0.1.0] - 2026-11-01

### Added
- Reads drops and renames from SQL, Rails, Django, Alembic, Knex and TypeORM raw SQL migrations.
- Finds old names in code, and flags releases that remove the code and the column together.
- Text, Markdown and JSON output, `--since`, `--last`, `--file`, `--all` and `--fail-on`.
- `checking-schema-drops` skill and plugin manifest.
